# 🛒 쇼핑몰 FrontEnd 프로젝트

> 순수 HTML, CSS, JavaScript를 활용한 반응형 쇼핑몰 웹사이트입니다.

---

## 📌 프로젝트 개요

본 프로젝트는 프레임워크 없이 순수 HTML, CSS, JavaScript만을 이용해 개발한 **정적 웹 기반 쇼핑몰 UI 프로젝트**입니다.  
실제 쇼핑몰의 흐름을 반영하여 상품 목록, 상세 페이지, 장바구니, 로그인 UI 등을 구현하였습니다.

---

## 🛠️ 사용 기술

| 구분       | 기술 스택              |
|------------|------------------------|
| 마크업     | HTML5                  |
| 스타일링   | CSS3, Media Queries    |
| 동작 구현  | JavaScript (Vanilla JS) |

---

## 🔧 주요 기능

- 메인 페이지 (배너/이벤트 영역 포함)
- 상품 리스트 페이지
- 상품 상세 보기
- 장바구니 기능 (수량 증가/삭제)
- 로그인/회원가입 화면 (UI만 구현)
- 반응형 디자인 (모바일 최적화)
