# 🛍️ 쇼핑몰 FrontEnd 프로젝트

> HTML, CSS, JavaScript를 활용한 쇼핑몰 UI 개발 프로젝트입니다.

---

## 📌 프로젝트 소개

본 프로젝트는 순수 HTML, CSS, JavaScript를 사용하여 제작된 **반응형 쇼핑몰 웹사이트**입니다.  
사용자 친화적인 UI/UX를 기반으로, 상품 목록과 상세 페이지, 장바구니 기능, 로그인 등 다양한 화면을 구현했습니다.

---

## ✨ 주요 기능

- 메인 배너 및 추천 상품 섹션
- 상품 목록 페이지
- 상품 상세 보기
- 장바구니 담기 및 수량 조정
- 로그인 UI 구현

---

## 🛠️ 사용 기술

- HTML5
- CSS3 (Flexbox, Media Query)
- JavaScript (Vanilla JS, DOM 조작)
